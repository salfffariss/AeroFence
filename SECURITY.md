# Security Policy

## Supported Versions

Only the latest major version of AeroFence receives security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability within **AeroFence**, please report it responsibly:

1. **Do not disclose the vulnerability publicly** in a GitHub issue, discussion, or pull request.
2. Please open a confidential report via **GitHub Security Advisories** on the repository page (Security tab -> Report a vulnerability).
3. If GitHub Security Advisories is not available, please contact the maintainers directly via private email.

### What to include in your report:
- A detailed description of the vulnerability.
- Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
- Expected vs. actual behavior.
- Operating system version and architecture (e.g., Windows 11 Build 22631 x64).

We strive to acknowledge receipt of reports within 48 hours and work with you to test and deploy a fix promptly.
